# MineStats Viewer for OBS

> 非公式のMinecraft向けファン制作MODです。Mojang StudiosおよびMicrosoftとは関係ありません。

Minecraft Java Edition 26.2 / Fabric 用のOBS統計オーバーレイです。
Minecraftを起動するとPC内だけでWeb画面を公開し、OBSへほぼリアルタイムに表示します。
外部アプリ、Python、stats JSONの監視は不要です。

シングルプレイでは統合サーバーが持つ最新の統計を直接読むため、ゲーム内の「統計」ボタンを押す必要はありません。

初期表示項目:

- 石・深層岩を掘った数
- ダイヤモンド鉱石を掘った数（通常＋深層岩）
- 死亡回数
- 各項目の累計と、現在のワールドへ入ってからの増加数

ゲーム内で記録される全統計から、表示するものを自由に追加できます。複数の統計を足す、引く、割合にする、目標までの残りや1時間あたりのペースを出すこともできます。

## いちばん簡単な導入方法（Modrinth App）

1. 念のため、遊ぶワールドをバックアップします。
2. [Modrinth App](https://modrinth.com/app) をインストールします。
3. Modrinth Appで `+` → `Create instance` を押します。
4. Minecraft `26.2`、Mod loader `Fabric` を選んで作成します。
5. 作ったインスタンスの `Mods` を開き、Fabric APIを追加します。
6. このプロジェクトの配布JAR（`mine-stats-viewer-for-obs-*.jar`）もModsへドラッグします。
7. Minecraftを起動してワールドへ入ります。
8. ブラウザで <http://127.0.0.1:8765/settings> を開き、表示内容を設定します。
9. OBSで「ソース」→「+」→「ブラウザ」を選び、URLへ `http://127.0.0.1:8765/overlay` を貼ります。幅 `700`、高さ `500` が目安です。

次回からはModrinth Appでこのインスタンスの「Play」を押すだけです。OBSの設定は残ります。

## Minecraft内から開く

Minecraftで `F8` キーを押すとMineStats Viewerメニューが開きます。

- 設定画面をブラウザで開く
- OBS用オーバーレイURLをクリップボードへコピー
- オーバーレイを普通のブラウザで確認

ワールドへ入ったときにも、チャット欄へF8キーの案内が一度表示されます。キーはMinecraftの「設定」→「キー設定」→「その他」→「MineStats Viewerメニューを開く」から変更できます。

## 表示内容を変更する

Minecraftを起動してから、ブラウザで <http://127.0.0.1:8765/settings> を開きます。

1. 上の検索欄に「ダイヤ」「死亡」「村人」などと入力します。
2. 表示したい統計の「追加」を押します。
3. カードの名前、累計／今回、色、アイコンなどを変更します。
4. 数字を組み合わせたい場合は、カード下部の検索欄から別の統計を足します。倍率を `-1` にすると引き算になります。
5. カードをドラッグすると並べ替えられます。

変更は自動保存され、右側のプレビューとOBSへ反映されます。設定ファイルは `config/mine-stats-viewer-for-obs.json` です。

画面上部ではタイトルの表示／非表示、テーマ色、文字色、背景色と透明度、枠線、余白、項目の横幅、名前と数字の間隔、文字サイズ、列数、角の丸さを変更できます。「マイクラ」「ダイヤ」「ネザー」「かわいい」「透明・シンプル」の見た目プリセットも用意されています。

「1080p」「1440p」「4K」の表示サイズプリセットを選ぶと、配信解像度に適したタイトル、文字、数字、アイコン、カード幅、余白へ一括調整されます。新規設定は1080p向けが標準です。OBS側のブラウザソースも配信キャンバスと同じ解像度にしてください。

「採掘」「ハードコア」「建築」「Mob狩り」「のんびり」の表示内容プリセットもあります。選択するとカード一式が作られ、その後で不要なカードの削除や別の統計の追加ができます。

統計検索にはMinecraftで現在選択している言語が使われます。日本語設定なら「ダイヤ」「死亡」「村人」などの日本語で検索できます。

## 以前から遊んでいるワールドを使う

使えます。Modrinth Appのインスタンス画面でフォルダーを開き、元のワールドフォルダーを `saves` へ丸ごとコピーしてください。

元のワールドは通常 `%AppData%\.minecraft\saves` にあります。同じワールドを元のランチャーとModrinthの両方で交互に開かず、コピー後はModrinth側を使ってください。26.2より古いワールドを初めて開く前には必ずバックアップしてください。

## OBSで映らないとき

- Minecraftでワールドに入っているか確認する
- 普通のブラウザで <http://127.0.0.1:8765/overlay> を確認する
- ポート8765を使う別アプリを終了してMinecraftを再起動する
- OBSのブラウザソースを右クリックし「更新」を押す

`127.0.0.1` だけで待ち受けるため、統計がインターネットへ公開されることはありません。

## マルチプレイについて

通常のマルチサーバーは統計の最新値をクライアントへ常時送らないため、このMODがバックグラウンドで約2秒ごとに統計を問い合わせます。ゲーム内の統計画面を開く必要はありません。シングルプレイは約250ms、マルチプレイはサーバー応答後（通常は約2秒間隔）で更新されます。

サーバーがバニラの統計リクエストを独自に無効化・制限している場合は更新できないことがあります。

## 開発・ビルド

JDK 25が必要です。

```powershell
./gradlew.bat build
```

完成したJARは `build/libs/` に生成されます。

# カスタマイズ機能設計

## 画面

- `/settings`: 配信者がブラウザで編集する画面
- `/overlay`: OBSに登録する透過画面
- 変更はMODの設定ファイルへ保存し、OBSへ即時反映する

## 初心者向けUX

初回は空の編集画面を出さず、用途を選ぶところから始める。

1. 「採掘」「ハードコア」「建築」「Mob狩り」「自由に作る」から選ぶ
2. 推奨カードが入った完成イメージを表示する
3. 不要なカードを目のボタンで隠す
4. カードをドラッグして並べ替える
5. 「OBSに追加」を押すと、URL・推奨サイズ・OBSでの操作手順を表示する

設定画面は常に左側を編集、右側を実寸プレビューにする。色、文字サイズ、余白、列数の変更は保存前から即座に見えるようにする。

統計の追加は内部IDを見せず、「ダイヤ」と検索すると「ダイヤモンド鉱石を採掘」「ダイヤモンドを拾った」「ダイヤモンドのツルハシを壊した」のように、人が理解できる候補をアイコン付きで表示する。

計算項目は最初に文章で選択する。

- 「いくつかの数字を足す」
- 「目標までの残りを出す」
- 「全体に占める割合を出す」
- 「1時間あたりのペースを出す」
- 「配信開始後に増えた数を出す」

自由数式、統計ID、JSON、画像パスなどは「上級者向け」を開いた場合だけ表示する。削除、初期化、プリセット変更には取り消しまたは確認を付ける。

画面内には専門用語を避けた短い説明を付ける。例: 「累計＝このワールドで今までに記録された数」「今回＝ワールドに入ってから増えた数」。保存状態、Minecraftとの接続状態、OBS接続状態も色と文章の両方で示す。

## 統計カタログ

Minecraftの `STAT_TYPE` レジストリから動的に列挙する。固定リストにしないことで、Minecraft更新や他MODが追加した統計にも追従する。

- 採掘したブロック
- クラフト、使用、破壊、拾得、ドロップしたアイテム
- 倒したMob、Mobに倒された回数
- 移動距離、プレイ時間、ダメージ、死亡、ジャンプなどのカスタム統計

統計IDは `統計タイプID|対象ID` とし、表示名はMinecraftの現在の言語設定から取得する。

## 表示項目

各カードは以下を個別設定できる。

- 名前、補足文
- Minecraftの任意アイテム／ブロックアイコン
- アイコンなし、絵文字、画像URL
- 累計、現在セッション、前回からの増加
- 数値、時間、距離、割合、小数桁、単位
- 文字色、強調色、背景色、サイズ
- 表示／非表示、並び順
- 数値変化時の点滅、ポップアップ、効果音

## 計算項目

自由数式は統計IDを変数として扱う。初心者向けには以下のプリセットを提供する。

- 合計: `石 + 深層岩`
- 差: `目標 - 現在値`
- 比率: `ダイヤ鉱石 / 全鉱石 * 100`
- 時速: `セッション増加 / セッション経過時間 * 1時間`
- 平均: `移動距離 / プレイ時間`
- 条件: `死亡回数 == 0 ? 生存中 : リカバリー中`

ゼロ除算、存在しない統計、負数、桁あふれは計算エンジン側で安全に処理する。JavaScriptの `eval` は使用しない。

## おすすめプリセット

- 採掘配信: 総採掘、鉱石合計、ダイヤ、ダイヤ率、ツルハシ破壊、時速
- ハードコア: 経過日数、生存時間、受けたダメージ、トーテム使用、目標日数
- RTA: 経過時間、移動距離、死亡、特定アイテム作成、区間差分
- 建築: 設置数相当のアイテム使用数、採掘数、クラフト数、作業時間
- Mob狩り: 総討伐、Mob別討伐、被討伐、1時間あたり討伐
- のんびり配信: 魚、繁殖、村人取引、睡眠、ケーキ、鐘

## アイコン

MinecraftのResource Managerから現在有効なリソースパックを読む。アイテムモデルを解決してテクスチャをローカルHTTPで返すため、バニラ以外のリソースパックやMODアイテムにも可能な範囲で追従する。解決できない複雑な動的モデルは、ユーザー指定画像またはフォールバックアイコンを使う。

## 保存と安全性

- `config/mine-stats-viewer-for-obs.json` に保存
- 設定変更APIは `127.0.0.1` からだけ利用可能
- 画像URLは任意で許可するが、初期値はMinecraft内蔵素材のみ
- 壊れた設定はバックアップして初期プリセットへ復旧
- 設定形式にバージョン番号を持たせ、将来マイグレーションする

# Streamer Preset Pack / 配信者向けプリセット集

MineStats Viewer for OBS 1.1.0以降で使える完成済み設定です。`ja`は日本語、`en`は英語表示です。

[12種類をまとめて見る](showcase.html)

## 使い方

1. Minecraftで`F8` → 設定画面
2. 「プリセット」→「設定ファイル」→「読込」
3. 好きなJSONを選択
4. 「OBSへ追加」に表示される推奨サイズをOBSへ入力

## 収録内容

| JSON名 | 向いている配信 | 形 |
|---|---|---|
| `pastel-pink-vtuber` | VTuber・雑談・採掘 | 淡いピンクの2列 |
| `pastel-blue-vtuber` | 冒険・雑談 | 淡いブルーの縦型 |
| `lavender-diamond-dream` | ダイヤ目標企画 | ラベンダーの2列 |
| `mint-cozy-chat` | 釣り・農業・生活 | ミントの2列 |
| `peach-building-log` | 建築 | ピーチの2列 |
| `transparent-bottom-bar` | 画面下へ常設 | 背景なし横長 |
| `mini-icon-counters` | 立ち絵の横 | 名前なし4カウンター |
| `dark-elegant-hardcore` | ハードコア | 黒×ゴールドの縦型 |
| `neon-mob-hunt` | Mob討伐企画 | ネオンの2列 |
| `cream-editorial-report` | 情報量の多い配信 | クリームの2列 |
| `monochrome-clean` | シンプルな画面 | 白黒の縦型 |
| `single-diamond-counter` | 単体目標カウンター | 大きな数字1つ |

読み込んだ後も、色・文字・項目・計算方法は通常どおり変更できます。時間表示のカードは、毎秒光らないよう強調を無効にしてあります。
